# Clique Forever

**Version:** 1.0.0  
**Client:** World of Warcraft: Forever (`_classic_beta_`, Interface **16001**)

Forever port of Clique (click-casting). Open the spellbook tab or use `/clique`.

**Not** an official Clique release.

## Install

1. Download this repo or the [Release](../../releases) zip.
2. Copy the `CliqueForever` folder into  
   `World of Warcraft\_classic_beta_\Interface\AddOns\`
3. Restart Forever (`WowB.exe`) or `/reload`, and enable the addon.

If you use “Download ZIP” from GitHub, keep the inner folder named **`CliqueForever`** (not `Clique-Forever-main`).
